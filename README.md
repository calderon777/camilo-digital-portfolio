# Camilo Calderon — Digital Portfolio

A responsive, bilingual static portfolio with a general profile and a Tesla-focused landing page.

## Preview

Open `index.html` in a browser. The language switch in the header toggles English and Spanish and remembers the visitor's choice.

## Pages

- `index.html` — biography, evidence, projects, experience and contact details
- `tesla.html` — targeted contribution map for Tesla applications
- `assets/camilo-calderon-digital-cv.pdf` — privacy-safe, digital-focused CV for public download

## Publish

The folder is ready for a static host such as GitHub Pages, Netlify, Cloudflare Pages or Vercel. The included public CV omits phone numbers and referee contact details; the original source CV remains untouched in the job-search folder.

## Suggested custom domain

Use a short name such as `camilocalderon.co.uk` or `camilo-calderon.com` if available.
